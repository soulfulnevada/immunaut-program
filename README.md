# Immunaut Program

A Kerbal-Space-Program-style biology game that runs in the browser. Design vaccines and drug treatments from parts, run trials in a 3D immune system, and learn from the debrief when things go wrong.

- **🌊 Outbreak:** Harbor Fever, three linked chapters. Investigate the pathogen, respond to the first wave, then face a second wave shaped by your choices.
- **📘 Tutorial:** 10 short missions, each teaching one idea. 5 on vaccines (carriers, antigens, adjuvants, delivery routes, boosters) and 5 on treatments (antibiotics, antivirals, dosing schedules, evolving drug resistance).
- **🧪 Sandbox:** design your own pathogen, then vaccinate against it or treat it.

One HTML file, built with [Three.js](https://threejs.org). Open `index.html` through any static server to play.

This is a game, not medical advice. The immunology is heavily simplified, and every pathogen is made up.
